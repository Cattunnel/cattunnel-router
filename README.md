# CatTunnel для роутеров

English: [README.en.md](README.en.md)

CatTunnel для роутеров: роутерная редакция VPN-клиента [CatTunnel](https://github.com/Cattunnel/cattunnel) для **OpenWrt** (23.05, 24.10, 25.x; страницы в LuCI), **Keenetic** и **ASUS Merlin** (Entware; своя веб-страница). Она закрывает устройства, на которые приложение не поставить (телевизор, приставка, консоль), и использует то же сетевое ядро и ту же подписку, что приложение. Управление: команда `cattunnel`, страницы LuCI или веб-страница.

## Репозитории CatTunnel

| Репозиторий | Что это |
|---|---|
| [Cattunnel/cattunnel](https://github.com/Cattunnel/cattunnel) | Приложение для Android, Windows и Linux |
| [Cattunnel/cattunnel-router](https://github.com/Cattunnel/cattunnel-router) | Роутерная редакция для OpenWrt, Keenetic и ASUS Merlin (этот репозиторий) |
| [Cattunnel/cattunnel-server](https://github.com/Cattunnel/cattunnel-server) | Сервер: форк TrustTunnel endpoint с транспортом NineLives |

## Возможности

**Режимы**

| Режим | Для кого | Как работает |
|---|---|---|
| `socks` (по умолчанию) | OpenWrt с mihomo/nikki (схема nikki + mihomo) | SOCKS5 на `127.0.0.1:1080` (TCP и UDP). mihomo сам решает, что пускать в CatTunnel; маршрутизация, zapret и AdGuard Home остаются как были |
| `tun` | Роутер без внешнего прокси: OpenWrt без mihomo, Keenetic, ASUS Merlin | устройство `tt0`, движок ставит маршруты, весь LAN или выбранные устройства идут в туннель (локальные сети мимо) |

**Подключение и обход блокировок** (то же ядро, что в приложении 1.5.9.5, ревизия `b59debf4`)

- Анти-DPI: способы 1-3, «Авто» (перебор по 15 с с проверкой интернета, удачный способ запоминается для сервера) и своя строка в синтаксисе ByeDPI.
- Отпечаток TLS: `chrome`, `firefox`, `safari`, `okhttp`.
- Маскировка размеров HTTP/2 (число кадров с набивкой; остальные параметры берутся из ядра по умолчанию) и отключение QUIC.
- Пул соединений: 2-4 TLS-соединения с сервером и пауза 2-6 с между рукопожатиями вместо залпа при старте.
- Имя сервера (SNI) и остальные параметры приходят из подписки готовыми секциями для движка.
- Всё это задаёт подписка; роутер может переопределить значения общими (`OVR_*`) или посерверными (`SRV_<ключ>_*`) настройками.
- Пока не поддерживаются: транспорт NineLives и профиль «Chrome 156». TLS-ключ авторизации `client_random_auth_key` не работает на mips/mipsel (там ядро собрано с OpenSSL); доступ определяют логин и пароль.

**Подписка**

- Импорт одноразовой ссылки от сервера подписок (`/api/go/<код>`) или `cattunnel://subscription?code=...&base=...`: роутер обменивает код на постоянные адреса подписки с привязкой к своему открытому ключу. Прежняя постоянная ссылка тоже поддерживается.
- При импорте или первом обновлении роутер создаёт свой ключ устройства age (`device.key`) и отправляет серверу открытую часть. Старый ключ пользователя (`age.key`) остаётся запасным для прежних серверов; одноразовый код не записывается в настройки.
- Сервер подписок должен отдавать список в формате для роутера (`?format=router`, строка `# cattunnel-router 1` в начале). Не скачалось: роутер пробует зеркала из прошлой подписки. Формат подписки в приложении: [docs/subscriptions.md](https://github.com/Cattunnel/cattunnel/blob/main/docs/subscriptions.md).

**Сеть и надёжность**

- Kill switch включён по умолчанию, в том числе для каждого выбранного устройства.
- Только выбранные устройства (`DEVICES`: MAC, имя из DHCP или префикс имени со «*»), туннель по требованию: движок запускается первым пакетом выбранного устройства и останавливается после 10 минут тишины (`IDLE_STOP`).
- Российские сайты напрямую (`RU_DIRECT`): домены, встроенный список сервисов и сети geoip:ru, обновление раз в 20 часов.
- Сторож: проверка туннеля каждые 30 с, переход на следующий сервер подписки после 2 минут без ответа, попытка вернуться раз в 30 минут.
- Строгая проверка сертификатов: набор корней строится из бандла роутера без российского корня.
- Обновление: раз в сутки проверяется `install.sh` последнего релиза с подписью Ed25519; `cattunnel upgrade` с откатом при ошибке.

## Установка

```
curl -fsSLO https://github.com/Cattunnel/cattunnel-router/releases/latest/download/install.sh && sh install.sh
```

Установщик выбирает пакет по системе и процессору, проверяет память, ядро, место и SHA-256 скачанных файлов. Первая команда загружает `install.sh` по HTTPS; проверка его подписи выполняется отдельно ([docs/install.md](docs/install.md#проверка-подписи)), а при `cattunnel upgrade` она обязательна.

Пакеты по архитектурам, установка без интернета, ручная установка на OpenWrt, Keenetic и ASUS Merlin: [docs/install.md](docs/install.md).

## Настройка

```
cattunnel import '<ссылка подписки>'   # ключ устройства создаётся автоматически
cattunnel list                       # серверы; * - выбранный
cattunnel use <ключ>                 # выбрать сервер из «cattunnel list»
/etc/init.d/cattunnel start          # Keenetic / Merlin: /opt/etc/init.d/S99cattunnel start
cattunnel test                       # «ok: интернет через туннель есть»
```

Режим `tun` на OpenWrt без внешнего прокси: `cattunnel set MODE tun && cattunnel firewall on && /etc/init.d/cattunnel restart`.

Настройки хранятся в `/etc/cattunnel/cattunnel.conf` (Entware: `/opt/etc/cattunnel/cattunnel.conf`); `cattunnel settings` показывает их, `cattunnel set ИМЯ значение` меняет. Список настроек, устройства через VPN, российские сайты напрямую, встраивание в nikki/mihomo и веб-страница: [docs/settings.md](docs/settings.md).

На OpenWrt страницы находятся в LuCI: «Службы → CatTunnel». На Keenetic и ASUS Merlin: `cattunnel web password <пароль>`, затем `cattunnel web on` и `http://<адрес роутера>:8090`.

## Сборка

`./build_packages.sh <версия> [arch...]` собирает пакеты в `build/` из готовых бинарников ядра (`engine/build_router.sh`) и статического age. Подробно: [docs/build.md](docs/build.md).

## Что нового

**1.5.9.5**
- Ядро той же ревизии, что приложение 1.5.9.5 (`b59debf4`): ротация IP. Если следующий сервер
  не отвечает или отказывает, он уходит на отдых, а туннель остаётся на текущем; когда отдыхают все
  серверы, повторная попытка ждёт конца ближайшего отдыха, без шторма переподключений.

**1.5.9**
- Ядро той же ревизии, что приложение 1.5.9 (`82963908`): 2-4 TLS-соединения с сервером и пауза
  2-6 с между рукопожатиями вместо залпа при старте.
- Надёжное обновление: блокировка помнит процесс, время и загрузку роутера, незавершённое обновление
  (`upgrade.pending`) сбрасывается через 15 минут; `cattunnel stop --force` выходит из него, сохраняя
  настройки и подписку; откат удаляет файлы нового пакета, которых не было в копии.
- Транспорт NineLives и профиль «Chrome 156» в роутерной версии пока не настраиваются.

**1.5.5**
- Ядро с патчем `0002-network-monitor-policy-routing.patch`. Монитор сети в ядре искал маршрут по
  умолчанию только в таблице `main`; где маршруты разложены по своим таблицам (`ip rule`: mwan3,
  pbr, свои схемы), после любой смены адресов или маршрутов движок решал «сети нет» и ждал её
  бесконечно - сторож видел мёртвый туннель и перебирал серверы. Теперь движок спрашивает само ядро,
  есть ли маршрут в интернет, и переподключается, только если сменился адрес выхода. На обычном
  OpenWrt, Keenetic и Merlin поведение прежнее.

**1.5.4**
- Сторож больше не падает на свежей установке (пока не было ни одной проверки обновлений):
  раньше это давало переподключение каждые ~37 с. Тот же шаблон исправлен в работе с nikki.

**1.5.3**
- Нет «осиротевших» движков: при остановке сторож сам гасит свой движок, лишние движки
  убиваются перед каждым запуском. `install.sh --from <папка>` - установка без интернета.
  `cattunnel doctor`: понятнее про память, swap и zram.
