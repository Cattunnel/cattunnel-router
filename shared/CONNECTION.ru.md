# Как устроено подключение

Коротко, по шагам — от ядра до сервера. Настройки каждого шага — в настройках ключа (раздел и кнопка «?» у него).

## 1. Ядро

- Соединение строит **ядро TrustTunnel** — нативная библиотека внутри приложения. В CatTunnel оно собрано с нашими доработками: приёмы обхода блокировок, своя строка обхода, маскировка размеров, понятные причины неудачи.
- Туннель — это обычное защищённое соединение HTTPS (HTTP/2 поверх TLS, или HTTP/3 поверх QUIC) с сервером. Внутри него идёт весь твой трафик.

## 2. Рукопожатие (TLS)

- Соединение начинается с **ClientHello** — первого пакета, в котором открытым текстом стоит имя сервера (SNI). Именно его читает фильтр провайдера (ТСПУ).
- **Отпечаток TLS** — каким приложением выглядит это рукопожатие. По умолчанию — как твой браузер, чтобы с твоего адреса фильтр видел один и тот же отпечаток. Менять без нужды не стоит.

## 3. Анти-DPI

- Меняет только то, **как ClientHello уходит в сеть**: пакет остаётся целым для сервера, а фильтр видит его разрезанным или не по порядку. Только HTTP/2.
- **Обычный** — пакет двумя кусками с паузой.
- **1, 2, 3** — приёмы из ByeDPI: «срочный» байт, который сервер выбрасывает, и кусок с TTL 1, который теряется по дороге и потом приходит повторно.
- **Авто** — пробует 1, 2, 3 по очереди и запоминает удачный для этого сервера и сети.
- **Своя строка** — как в ByeDPI: части `-s`, `-o`, `-d` с позицией, например `-o1+s -d3+s`. Синтаксис — в «?» у раздела «Обход блокировок».

## 4. Маскировка размеров

- Первые кадры соединения дополняются случайными байтами, чтобы размеры первых запросов туннеля не повторялись. Это часть стандарта HTTP/2, сервер ничего не настраивает.
- Включается в «Для экспертов»; по умолчанию выключена.
- **Отключить QUIC** (там же): приложения внутри туннеля не могут ходить по UDP на порт 443 — это QUIC, на нём работают YouTube и Chrome. Они сразу переходят на обычный TCP. Помогает сравнить скорость и понять, мешает ли QUIC. По умолчанию выключено.

## 5. Соединение и повторы

- Если сервер не ответил, приложение знает почему: **нет TCP** (адрес недоступен), **сброс после ClientHello** (блок по имени) или **тишина после ClientHello**.
- **Тишина** похожа на «заморозку» адреса фильтром на пару минут. Каждое новое рукопожатие её продлевает, поэтому ядро ждёт минуту, «Авто» не перебирает способы, а Марсик не стучится со своими проверками и предлагает другой сервер.
- После сброса ядро ждёт 5 секунд: пачка рукопожатий подряд сама по себе выглядит подозрительно.

## 6. Сервер

- На сервере ничего настраивать не нужно: все приёмы работают со стандартным сервером TrustTunnel.
- Ключ (адрес, логин, пароль) приходит из ссылки или подписки. Подписка может сама задать способ обхода, отпечаток, свою строку, маскировку и отключение QUIC — тогда приложение берёт их оттуда.
