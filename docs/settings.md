## Файл настроек и команда set

Настройки хранятся в `/etc/cattunnel/cattunnel.conf`, на Entware в `/opt/etc/cattunnel/cattunnel.conf`. UCI для них не используется. `cattunnel settings` показывает значения, `cattunnel set ИМЯ значение` меняет их. За один вызов можно передать несколько пар: `cattunnel set MODE tun KILLSWITCH on`.

Значения проверяются при записи, параметры движка применяются при перезапуске службы. Смена `MODE` сама службу не запускает и профиль внешнего прокси не меняет.

| Группа | Имя и допустимые значения (умолчание) |
|---|---|
| Режим и служба | `MODE socks\|tun` (`socks`), `SOCKS <IPv4:порт>` (`127.0.0.1:1080`), `TUN_DEV <имя>` (`tt0`), `LOGLEVEL error\|warn\|info\|debug` (`info`), `SERVER <ключ>`, `SUB_URL <ссылка>` |
| Маршрутизация | `KILLSWITCH on\|off` (`on`), `RU_DIRECT on\|off` (`on`), `DNS router\|tunnel` (`router`), `MTU 1200-1500` (`1350`), `DEVICES '<MAC или имена через пробел>'` (пусто), `IDLE_STOP <секунды>` (`600`) |
| Сторож | `FAILOVER on\|off` (`on`), `AUTO_WAIT` (`15`), `CHECK_EVERY` (`30`), `CHECK_FAILS` (`4`), `BACK_AFTER` (`1800`), всё в секундах, кроме `CHECK_FAILS` |
| Переопределения подписки | `OVR_TLS chrome\|firefox\|safari\|okhttp`, `OVR_DPI off\|1\|2\|3\|auto\|custom`, `OVR_DESYNC '<строка>'`, `OVR_PADDING <число>` (до 64), `OVR_QUIC on\|off` |
| Веб-страница и интеграция | `WEB on\|off`, `WEB_PORT <число>` (`8090`), `NIKKI on\|off` |

Переопределения по умолчанию пусты, и тогда действует значение подписки. Для одного сервера есть `SRV_<ключ>_TLS`, `_DPI`, `_DESYNC`, `_PADDING` и `_QUIC`: пустая строка наследует общее переопределение, `sub` возвращает значение подписки. `OVR_PADDING` задаёт число кадров HTTP/2 с набивкой (`h2_padding_frames` в конфиге движка). Остальные умолчания движка: от 1 до 64 байт на кадр, 2048 байт на поток и 4096 байт на сессию. `OVR_QUIC on` блокирует QUIC. Службы настраиваются отдельно: `cattunnel web password\|on\|off\|status` и `cattunnel nikki on\|off\|status`.

## Остановка и обновление

Обычная остановка (`cattunnel stop`, init-скрипт, кнопка «Остановить») возвращает DNS и правила устройств к прямому доступу и сохраняет настройки и подписку. Перезапуск службы и переключение сервера используют внутреннюю остановку с сохранением блокировки. Пока действует метка `upgrade.pending`, обычный `stop` тоже сохраняет защиту. Явно выйти во время незавершённого обновления можно командой `cattunnel stop --force`, её же вызывают кнопки «Остановить» в LuCI и на веб-странице.

Блокировка установщика хранит PID, время и идентификатор загрузки. Если процесс умер или прошло 15 минут, установку можно повторить. Метка `upgrade.pending` тоже действует 15 минут. Завершившийся установщик ждёт подключения до 5 минут и затем снимает временный барьер. Для остановленной службы и для Entware с `autostart.off` барьер установки не включается.

## Два режима

| Режим | Для кого | Как работает |
|---|---|---|
| `socks` (по умолчанию) | OpenWrt с mihomo или nikki | SOCKS5 на `127.0.0.1:1080` (TCP и UDP). mihomo сам решает, что отправить в CatTunnel, а маршрутизация, zapret и AdGuard Home остаются как были |
| `tun` | Роутер без внешнего прокси: OpenWrt без mihomo, Keenetic, ASUS Merlin | устройство `tt0`, движок ставит маршруты, весь LAN идёт в туннель, локальные сети мимо |

## Только некоторые устройства через туннель

Режим `tun`, параметр `DEVICES`.

```
cattunnel set MODE tun DEVICES 'aa:bb:cc:dd:ee:ff Phone*'   # MAC, имя или начало имени со «*», через пробел
cattunnel firewall on && /etc/init.d/cattunnel restart       # Entware: /opt/etc/init.d/S99cattunnel restart
cattunnel devices status
```

При непустом `DEVICES` в туннель идут только выбранные устройства, остальные остаются на обычном маршруте. При пустом списке туннелем пользуется весь LAN. В режиме `socks` маршрутизацию задаёт внешний прокси, а `DEVICES` определяет только область временной блокировки при обновлении и перезапуске.

Параметр `IDLE_STOP` по умолчанию равен 600 секундам. Пока выбранные устройства не обращаются в интернет, движок не работает, а после периода тишины он снова останавливается. Первый пакет устройства запускает движок. `IDLE_STOP 0` отключает остановку по тишине.

```text
устройство --> роутер: пакет с MAC из DEVICES --> метка 0x1801
                                                       |
                  таблица маршрутов 218 <--------------+
                       |            |
              есть tt0: в туннель   нет: unreachable (kill switch)
```

Рисунок 1. Как пакеты выбранных устройств попадают в туннель.

Пакеты выбранных устройств помечаются по MAC: на OpenWrt таблицей nftables `inet cattunnel_dev`, на Entware цепочкой iptables `CATTUNNEL_DEV`. Метка отправляет пакеты в таблицу маршрутизации 218 с выходом через `tt0`, исключениями для локальных сетей и маршрутом `unreachable` при включённом kill switch. Правила применяются и к IPv6.

Имена устройств берутся из DHCP, а на Keenetic ещё из `ndmc show ip hotspot`. Сторож сверяет их каждые 30 секунд. Имя или префикс со звёздочкой позволяет находить телефон после смены частного MAC. Если телефон имя не сообщает, нужен постоянный MAC. Результат показывает `cattunnel devices status`.

При `DNS tunnel` запросы выбранных устройств на порт 53 уходят на DNS из подписки, а DNS остальных устройств не меняется. В LuCI список задаётся в «Настройки → Только эти устройства».

## Российские сайты напрямую

Режим `tun`, параметр `RU_DIRECT` (по умолчанию `on`).

`RU_DIRECT on` добавляет исключения для российских доменов, встроенного списка сервисов и сетей geoip:ru. Встроенный список лежит в `/usr/share/cattunnel/ru_services.txt` (Entware: `/opt/usr/share/cattunnel/ru_services.txt`). Скачанные сети хранятся в `ru.cidr` и обновляются раз в 20 часов, при сбое остаётся прежний список.

Исключения применяет движок к трафику внутри `tun`, включая пакеты выбранных устройств. Сетевые исключения не требуют разрешения доменного имени. Состояние показывает `cattunnel ru status`, ручное обновление делает `cattunnel ru update`, отключить можно так: `cattunnel set RU_DIRECT off` и перезапуск.

## Схема с nikki и mihomo

1. Поставьте пакет и подписку, как выше. Режим `socks` включён по умолчанию.
2. `cattunnel mihomo` печатает готовые строки для профиля mihomo: прокси `CatTunnel` (socks5, udp), группу `VPN` типа `fallback` (CatTunnel, затем VLESS-REALITY) и правила `DIRECT` для самого туннеля: процесс `trusttunnel_client` и адреса серверов CatTunnel. Эти правила ставьте самыми первыми, иначе соединение движка с сервером уйдёт в mihomo и замкнётся на себя.
3. Добавьте `VPN` первой в селекторы `PROXY`, `YOUTUBE` и `FINAL` и перезапустите nikki (`service nikki restart`).
4. Проверьте командой `cattunnel test`. В LuCI на странице Nikki группа `VPN` должна показывать CatTunnel живым.

Вместо ручной правки можно выполнить `cattunnel nikki on`: он встраивает CatTunnel через mixin nikki (группа `CatTunnel-VPN`) и умеет откатиться командой `off`.

VLESS остаётся запасным выходом группы `fallback`, и доступность проверяет mihomo. Это настройка mihomo, а `FAILOVER` переключает серверы внутри подписки CatTunnel, это разные вещи.

## Веб-страница на Keenetic и ASUS Merlin

В родной веб-интерфейс Keenetic встроиться нельзя, поэтому у CatTunnel своя страница. Это те же страницы LuCI (Состояние, Серверы, Настройки, Диагностика), запущенные через небольшую прослойку `www/luci-shim.js` вместо LuCI. Команды страниц идут в `cgi-bin/api` с тем же списком разрешённого, что в ACL LuCI.

```
cattunnel web password <пароль>      # от 8 символов, пользователь admin
cattunnel web on                     # затем http://<адрес роутера>:8090
```

`lighttpd` с модулями mod_cgi, mod_auth и mod_authn_file ставится сам. Он слушает только домашний адрес роутера (`br0` на Keenetic и Merlin, `br-lan` на OpenWrt), порт открыт в фаерволе только для домашней сети, вход по паролю. Если порт 8090 занят, берётся ближайший свободный из следующих десяти. Изменения принимаются только POST-запросом с заголовком `X-CatTunnel: 1`, а значения проверяет `cattunnel set`. Хук netfilter на Keenetic возвращает правило после перестроек.

На странице: состояние, запуск и остановка, устройства сети с галочками «через VPN», сервер, kill switch, российские сайты напрямую, минуты тишины. `cattunnel web off` выключает страницу, `cattunnel web status` показывает состояние.

На OpenWrt страницы доступны в LuCI: «Службы → CatTunnel». Отдельную веб-страницу там тоже можно включить командой `cattunnel web on`.
